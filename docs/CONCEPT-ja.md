# Foldlyticsを作った理由

[English](CONCEPT.md)

## このアプリで答えたいこと

折りたたみスマホをほとんど開かないなら、少し重くて高価な普通のスマホを持ち歩いているのと変わりません。

だからといって、折りたたみに価値がないわけではありません。大きな内側画面で読書、動画、地図、マルチタスク、仕事が快適になる人もいれば、ほとんど閉じたまま使う人もいます。スペック表やレビューを読んでも、次の問いには答えられません。

> 折りたたみという形は、自分のスマホの使い方を本当に良くしているのか。

Foldlyticsを作ったのは、記憶だけではこの問いに答えられないからです。「あまり開いていない気がする」で終わらせず、数か月分の使い方を記録に残します。

## 買い替えるときの判断材料にする

Foldlyticsは、毎日のスコアを上げたり、アプリを開く回数を増やしたりするためのものではありません。折りたたみスマホを買い替えるとき、次の問いに答えるためのアプリです。

> 次のスマホも折りたたみにするべきか。

その判断には、もう少し具体的な数字が必要です。

1. 判定できた端末利用時間のうち、内側ディスプレイは何割だったか。
2. 記録のある1日あたり、何回くらい「開いた」を検出したか。
3. 記録のある日のうち、内側を一度でも使った日は何日だったか。
4. 内側ディスプレイで表示していたアプリは何か。
5. 新しい端末への物珍しさが落ち着いた後も、内側を使い続けたか。
6. その答えを信頼できるだけの記録が残っているか。

## 設計で大切にしたこと

### 1. 長く記録する

1日の使い方は、旅行、仕事、体調、新しく入れたアプリなどに左右されます。
数週間から数か月、できれば1年以上記録した方が、折りたたみが自分に合うかを判断しやすくなります。そのため、Foldlyticsは長期の履歴を保存します。

### 2. 分からないところを推測で埋めない

Androidには、完全な物理ヒンジカウンターも、無期限で欠損しない利用履歴もありません。
端末の再起動、バックグラウンド処理の遅れ、画面構成イベントの欠損、権限の変更などで、記録に空白が生じます。

Foldlyticsは、その空白を推測した外側・内側の利用時間で埋めません。連続した根拠がある`外側 -> 内側`を「開いた」、`内側 -> 外側`を「閉じた」と数えます。前後の状態が分からない境界は、分からないまま残します。

その結果、記録に空白が残ることはありますが、推測値を実際の利用記録として見せることはありません。

具体的な数え方と制約は[MEASUREMENT-ja.md](MEASUREMENT-ja.md)にまとめています。

### 3. 利用履歴を端末内に記録する

アプリの利用状況からは、仕事、興味、健康上の関心、人間関係、生活習慣まで推測できる可能性があります。Foldlyticsは、この履歴を端末内に保存します。

- アカウントを作らない。
- ネットワーク権限を持たない。
- 広告SDK、分析SDKを入れない。
- 外部サーバーへ自動送信しない。
- ローカル履歴をクラウドバックアップしない。
- エクスポートと共有は、ユーザーが明示的に操作したときだけ行う。

個人的な利用履歴を長く記録するなら、これらは必要な条件だと考えています。

## Foldlyticsがしないこと

- 単なる物理ヒンジのカウンターにはしない。
- 異なる利用者同士を比べるベンチマークにはしない。
- 生産性やデジタルウェルビーイングを評価しない。
- ペアレンタルコントロールや従業員監視には使わない。
- クラウド分析サービスにはしない。
- すべてのAndroid端末が同じイベントを返すとは仮定しない。
- Androidに残っていないデータを推測で復元しない。

## 数か月後に分かればよいこと

折りたたみスマホを数か月から1年使った後に、「大きな画面を使った気がする」より具体的に振り返れるようにしたいと考えています。

記録のある日の多くで内側を使い、内側で表示した時間が長いアプリが分かれば、次も折りたたみにするか考える材料になります。内側を使う割合が最初の1か月を過ぎて下がったままなら、次は普通のスマホにするという判断もできます。記録の欠損が多い場合は、まだ判断できません。そのときは、データが足りないことを表示します。

結論が「次は折りたたみを買わない」でも構いません。自分の利用履歴を見て次の端末を選べたなら、このアプリを作った意味があります。
